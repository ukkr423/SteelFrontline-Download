# 鋼鉄の戦線 / STEEL FRONTLINE

コクピット視点のロボット対戦FPS（試作版）です。ひとりでAIと戦うことも、友達とオンラインで対戦することもできます。

## ダウンロード

最新版：**Ver 1.2.0**（2026-11-06）。バージョンはゲームのタイトル画面の左下に出ます。

**[▶ 最新版をダウンロード（Windows・zip 約35MB）](https://github.com/ukkr423/SteelFrontline-Download/releases/latest/download/SteelFrontline-Windows.zip)**

過去の版や更新内容は [リリース一覧](https://github.com/ukkr423/SteelFrontline-Download/releases) にあります。

- 対応：Windows 10 / 11（64ビット）。インストールは不要です。
- zipを右クリック →「すべて展開」してから、中の `SteelFrontline.exe` を起動します。zipの中から直接は起動できません。
- 「WindowsによってPCが保護されました」と出たら、「詳細情報」→「実行」を押してください（署名のない自作ゲームのため出ます）。
- 詳しい遊び方は、zipに入っている「はじめにお読みください.txt」にあります。

## 友達と対戦する

- ポートは **UDP 7620** です。部屋を作る人（ホスト）は、ルーターでUDP 7620番をそのPCへ転送しておきます。参加する人はルーターの設定は不要です。
- 参加する人は、タイトルの「オンライン対戦」で、接続先のボタン（サーバーPC本体 / 同じLAN / インターネット）を選ぶか、ホストから教わったIPアドレスを入力して「サーバーに参加する」を押します。
- **全員が同じバージョンを使ってください。** 違うと「参加できませんでした」と出ます。新しい版が出たら、全員（専用サーバーも）入れ替えてください。
- 声が送れないときは、Windowsの「設定」→「プライバシーとセキュリティ」→「マイク」で、デスクトップアプリがマイクを使えるか確かめてください。
- ホストは待機室で「観戦する」を押すと、出撃せずに試合を観戦できます（全機体の名前・体力が見え、どの機体でも三人称・一人称で追えて、両チームのボイスチャットが聞こえます）。
- 各チームの機数（1〜8機）とチームコストは、待機室でホストが決めます（専用サーバーでは、最初に入った人が「リーダー」として決めます）。空いた枠はAIが戦います。
- 試合後は全員の順位とMVPが表示され、そのあと全員が待機室に戻ります。チーム・機体を選び直して次の試合を始めます。サーバーを再起動する必要はありません。
- オンラインでは、機体の上にパイロット名と体力バーが出ます。

## 基本操作

| キー | 動作 |
|---|---|
| WASD / マウス | 移動 / 旋回・照準 |
| 左クリック / 右クリック | メイン射撃 / サブ射撃（機体ごとに違う） |
| Space 長押し / Shift＋移動 | ブースト上昇 / ブーストダッシュ |
| C | しゃがむ（遮蔽物に隠れる） |
| Tab / R | ロック切り替え / リロード |
| T（長押し） | ボイスチャット（オンラインで味方チームだけに届く。設定で常時オン・オフも選べる） |
| Esc | メニュー |

ゲームパッド（Xbox系）でも遊べます。
